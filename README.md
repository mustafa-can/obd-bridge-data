# OBD Bridge DTC kataloğu

Bu depo, OBD Bridge uygulamasının arıza kodu açıklama verisini
barındırır. Dosyalar `manifest.json` içindeki SHA-256 özetleriyle
doğrulanır.

- **Genel + marka listeleri** (`dtc_codes.json`) — MIT / GPL-3.0 — https://github.com/Wal33D/dtc-database
- **PSA (Peugeot / Citroën / DS)** (`dtc_psa.json`) — GPL-3.0 — https://github.com/ludwig-v/arduino-psa-diag
- **OEM ECU tanımları** (`dtc_oem.json`) — GPL-3.0 — https://github.com/laravelcompany/ecudocs.com
- **Marka listeleri (ek)** (`dtc_extra.json`) — GPL-2.0 — https://github.com/dsoprea/DtcLookup
